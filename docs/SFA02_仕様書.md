# SFA02 商談管理システム（Power Ageless）仕様書

> ビジネスサイド向け簡易仕様書
> 最終更新日: 2026/3/31

---

## 1. システム概要

**Power Ageless** は、人材ビジネスにおける商談・企業・求人・タスクを一元管理するためのSFA（Sales Force Automation）システムです。

### 対象ユーザー
- 営業担当者（ITSS / PERM / DSL / FS 各事業部）

### 事業部区分

| 事業部コード | 正式名称 | 概要 |
|:---:|---|---|
| ITSS | ITシステムサービス | ITエンジニアのSES派遣 |
| PERM | パーマネント | 正社員紹介（人材紹介） |
| DSL | デジタルソリューション | AI・データ系コンサル人材 |
| FS | フルソリューション | 総合ソリューション営業 |

## 2. 画面一覧と主要機能

### 2-1. 商談一覧（/deals）

商談の検索・一覧表示画面。

**表示項目:**
| 項目 | 説明 |
|---|---|
| 商談名 | 商談の名称 |
| 企業名 | 取引先企業 |
| 担当者 | 自社の営業担当者 |
| 事業部 | ITSS / PERM / DSL / FS |
| 最終商談日 | 直近の打ち合わせ日 |
| ステータス | 予定 / 実施済 / 完了 |

**絞り込み条件:**
- 事業部（ITSS / PERM / DSL / FS）
- 担当者
- 商談経路（toBマーケ / IS / 営業顧問 など）
- ステータス（予定 / 実施済 / 完了）
- フリーワード検索（企業名・商談名）

**操作:**
- 「新規商談」ボタンで商談を新規作成
- 各行クリックで商談詳細画面へ遷移

---

### 2-2. 商談詳細（/deals/:id）

個別の商談情報を閲覧・管理する画面。

**基本情報エリア（左カラム）:**
| 項目 | 説明 |
|---|---|
| 商談名 | 商談の名称 |
| 企業名 | 取引先企業（企業詳細へリンク） |
| 先方部署 | クライアントの部署名 |
| 先方担当者 | クライアント側の担当者名 |
| 自社担当者 | 当社の営業担当者 |
| 事業部 | 担当事業部 |
| 経路 | 商談の獲得経路 |
| 獲得者 | 商談を獲得した営業担当者 |
| ステータス | 予定 / 実施済 / 完了 |

**商談ツリー:**
商談の親子関係・分岐を視覚的にツリー表示します（詳細は後述）。

**商談履歴（ミーティング一覧）:**
- 日付・回数・参加者・内容を時系列で表示
- 各回の内容は折りたたみ表示（クリックで展開）

**タスク一覧:**
- 商談に紐づくタスクを表示
- ステータスをインラインで変更可能（未実施 / 実施中 / 完了）

**求人一覧:**
- 商談から発生した求人案件を表示
- 職種名・募集人数・事業部を表示

**アクションボタン:**
| ボタン | 機能 |
|---|---|
| タスク追加 | 商談に紐づくタスクを登録 |
| 求人登録 | 商談から求人案件を新規作成 |
| 商談追記 | 同じ担当者の続きの商談を追加（横チェーン） |
| 担当分岐 | 別の担当者・部署への商談分岐を作成（縦分岐） |
| 削除 | 商談を削除（確認ダイアログあり） |

### 2-3. 企業一覧（/companies）

取引先企業の検索・一覧表示画面。

**表示項目:**
| 項目 | 説明 |
|---|---|
| 企業名 | 取引先企業名 |
| ティア | Enterprise / Mid / SMB |
| 分類 | SIer / SES派遣 / コンサル / Web系 / 一般事業 |
| ITSS | ITSS事業部の契約状況 |
| PERM | PERM事業部の契約状況 |
| DSL | DSL事業部の契約状況 |
| 最終商談日 | 最後に商談を行った日付 |

**絞り込み条件:**
- ティア（Enterprise / Mid / SMB）
- 分類（SIer / SES派遣 / コンサル / Web系 / 一般事業）
- 各事業部の契約ステータス（未接触 / 商談中 / 契約中 / 契約終了）
- 90日未接触フィルタ（ON/OFF切替）
- フリーワード検索（企業名）
- 最終商談日ソート（昇順 / 降順）

**操作:**
- 「新規企業追加」ボタンで企業を新規登録
- 各行クリックで企業詳細画面へ遷移
- ゴミ箱アイコンで削除

---

### 2-4. 企業詳細（/companies/:id）

個別の企業情報を閲覧・管理する画面。

**基本情報:**
- 企業名、ティア、分類、粗利実績

**契約ステータス:**
- ITSS / PERM / DSL それぞれの契約状況を表示
- ステータス変更ボタンで更新可能
- ステータス区分: 未接触 → 商談中 → 契約中 → 契約終了

**ホワイトリスト（部署別コンタクト管理）:**
| 項目 | 説明 |
|---|---|
| 部署名 | クライアント企業内の部署 |
| コンタクト先 | 担当者名・役職 |
| コンタクト済 | 接触済みかどうか |
| 求人獲得 | 求人を獲得できたかどうか |

**商談ツリー（事業部別）:**
- 企業に紐づく全商談をツリー形式で表示
- 事業部別にタブ切替可能（全体 / ITSS / PERM / SFA）

**アクティビティカラム（3列）:**
- **求人:** 求人案件の一覧（ID・職種・担当者・ステータス・作成日）
- **CV SENT:** 候補者送付記録（日付・候補者名・送付先・単価）
- **面接 / 口頭合意:** 面接記録と口頭合意記録

**操作:**
- 新規商談登録、アクティビティ登録、タスク登録、契約ステータス更新、削除

### 2-5. Task一覧（/tasks）

タスク・アクティビティの管理画面。

**タスクとアクティビティの違い:**
| 種別 | 用途 |
|---|---|
| Task | 商談に紐づく具体的なTo-Do（例: 候補者リスト作成、提案書作成） |
| Activity | 日常的な営業活動の記録（例: 電話、メール、訪問） |

**表示項目:**
| 項目 | 説明 |
|---|---|
| 種別 | Task / Activity |
| タスク名 | タスクの名称 |
| 企業名 | 関連する企業 |
| カテゴリ | タスクの分類 |
| 期日 | 締め切り日 |
| 担当者 | 実施者 |
| ステータス | 未実施 / 実施中 / 完了 |

**絞り込み条件:**
- 担当者
- カテゴリ
- ステータス（未実施 / 実施中 / 完了 / 本日 / 期限切れ）
- 期限（今週 / 今月）
- 企業名
- 種別切替（全て / Task / Activity）

**操作:**
- ステータスをインラインで変更可能
- 新規タスク・アクティビティ作成
- ゴミ箱アイコンで削除

## 3. 商談ツリー機能

商談の親子関係と分岐構造を視覚的に表示する機能です。

### 3-1. ツリーの構造

```
初回商談（社長・人事部長）
├─ 製造事業部 レガシーマイグレーションPJ
│   ├─ 製造事業部 フェーズ2 クラウド移行
│   └─ 製造事業部 IoTプラットフォーム構築
│       ├─ IoT基盤 セキュリティ強化PJ
│       └─ IoT基盤 監視・運用自動化PJ
├─ DX推進室 スマートファクトリーPJ
│   ├─ DX推進室 AI品質検査PJ
│   └─ DX推進室 デジタルツイン基盤
├─ 金融ソリューション部 基幹刷新
│   └─ 金融ソリューション部 APIゲートウェイ構築
├─ 人事部 採用DX支援
└─ クラウド推進本部 マルチクラウド戦略支援
```

### 3-2. 操作の違い

| 操作 | ボタン名 | ツリー上の表示 | 用途 |
|---|---|---|---|
| **商談追記** | 商談追記 | 横方向に「-」で繋がる | 同じ担当者・部署の継続商談 |
| **担当分岐** | 担当分岐 | 縦方向に「└」で分岐 | 別の担当者・部署への展開 |

### 3-3. ツリーの表示ルール
- **現在閲覧中の商談:** 青枠・青背景で強調表示
- **他の商談:** クリックで遷移可能なリンク
- 同一企業の全ルート商談が一括表示される

## 4. データの関連図

```
企業 (Company)
  │
  ├── 商談 (Deal) ※複数
  │     │
  │     ├── ミーティング (Meeting) ※複数
  │     ├── タスク (Task) ※複数
  │     ├── 求人 (Job) ※複数
  │     │     │
  │     │     ├── CV SENT ※複数
  │     │     └── 面接 (Interview) ※複数
  │     │           └── 口頭合意 (Oral Agreement)
  │     │
  │     └── 商談ツリー（親子・分岐関係）
  │           ├── 商談追記 → 横チェーン (next)
  │           └── 担当分岐 → 縦分岐 (branches)
  │
  ├── ホワイトリスト（部署別コンタクト管理）
  └── 契約ステータス（ITSS / PERM / DSL 別）
```

## 6. ステータス定義

### 6-1. 商談ステータス

| ステータス | 説明 |
|---|---|
| 予定 | 商談が予定されている段階 |
| 実施済 | 商談を実施した段階 |
| 完了 | 商談が成約・完了した段階 |

### 6-2. タスクステータス

| ステータス | 表示名 | 説明 |
|---|---|---|
| pending | 未実施 | 未着手のタスク |
| in_progress | 実施中 | 作業中のタスク |
| done | 完了 | 完了したタスク |

※一覧画面では追加フィルタとして「本日」（今日が期日）「期限切れ」（期日超過）も使用可能

### 6-3. 契約ステータス（企業別・事業部別）

| ステータス | 説明 |
|---|---|
| 未接触 | まだコンタクトしていない |
| 商談中 | 商談を進めている段階 |
| 契約中 | 契約が締結され進行中 |
| 契約終了 | 契約が終了した状態 |

## 7. データソース

本システムは2つのデータソースに対応しています。

| モード | 説明 |
|---|---|
| **APIモード** | Google Apps Script (GAS) 経由でスプレッドシートと連携 |
| **ダミーモード** | API未設定時にローカルのサンプルデータで動作（デモ用） |

- API接続に失敗した場合、自動的にダミーモードにフォールバック
- ダミーモードでもCRUD操作は画面上で正常に動作（ブラウザ内のみ、永続化なし）
